# Contributing to Play JSON

Please follow the [Play Framework contribution guidelines](https://www.playframework.com/contributing).

For Play JSON contributions:

- Discuss larger changes and new features before submitting a pull request.
- Include tests for bug fixes and new functionality.
- Update the documentation when changing the API.
- Run the project's validation and formatting checks before submitting a pull request.
- Keep commits squashed before submitting the pull request.
